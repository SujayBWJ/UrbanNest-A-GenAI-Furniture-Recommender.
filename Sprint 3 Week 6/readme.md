# UrbanNest AI Recommender System

## Features

- Semantic furniture retrieval
- ChromaDB vector search
- Conversational recommendations
- FastAPI backend
- Streamlit dashboard
- RAG-style architecture

## Technologies

- Python
- FastAPI
- Streamlit
- ChromaDB
- SentenceTransformers
- LangChain

## Run API

uvicorn api.main:app --reload

## Run Dashboard

streamlit run dashboard/app.py
